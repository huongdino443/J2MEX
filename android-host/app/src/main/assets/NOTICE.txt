J2MEX — Android app for Java ME games

HOW IT WORKS
J2MEX runs FreeJ2ME on Android OpenJDK 8 ARM64 through the JNI Invocation API.
FreeJ2ME runs headlessly: its BufferedImage framebuffer is sent over an
authenticated loopback connection and Android renders the pixels directly.

SAFETY AND COMPATIBILITY
Only open trusted MIDlet JARs. A MIDlet runs with the app's permissions.
Compatibility can vary by game, particularly when a game relies on
manufacturer-specific APIs.

FEATURE VERIFICATION
All current J2MEX features have been tested directly on a device and confirmed
to work normally.

J2MEX — ứng dụng Android hỗ trợ chạy trò chơi Java ME

CÁCH HOẠT ĐỘNG
J2MEX chạy FreeJ2ME trên Android OpenJDK 8 ARM64 thông qua JNI Invocation API.
FreeJ2ME chạy ở chế độ headless: framebuffer BufferedImage được gửi qua kết
nối loopback đã xác thực và Android vẽ trực tiếp các pixel.

API riêng của nhà sản xuất.
