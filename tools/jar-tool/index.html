Giới hạn và lưu ý khi ghép

Tool đánh số bản bằng tiền tố a–z rồi aa–zz. Nhiều bản cần thêm RAM và dung lượng; mức tối đa thực tế tùy thiết bị.

Nếu thư viện hoặc tài nguyên trùng tên không thể ghép an toàn, tool sẽ dừng và báo lỗi thay vì xuất JAR có nguy cơ hỏng.

Chi tiết kỹ thuật
Framework menu gốc do Quyetdaik thực hiện; bản tích hợp và đóng gói trong tool này do TrVH thực hiện. Tool đổi namespace cho từng bản, chuyển các lớp MIDlet/UI/Thread sang thư viện tương thích, tách dữ liệu RecordStore và điều chỉnh các hàm Canvas cần thiết.
Tạo file cài đặt JAD

JAD chứa thông tin để một số trình cài đặt nhận diện JAR. Chọn file .jar để tạo JAD tương ứng.

      JAD được tạo như thế nào?
      
JAD được tạo từ các thuộc tính MIDlet-* trong MANIFEST.MF của JAR và tự thêm kích thước cùng tên file JAR. Nếu JAR không có manifest hợp lệ, công cụ sẽ báo lỗi.
